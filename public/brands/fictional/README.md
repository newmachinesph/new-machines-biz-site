# Fictional company identities

16 original fictional brands used in the New Machines homepage logo reel. They do not represent customers, affiliations, or endorsements. Each has an individual composition: wordmarks, monograms, stacked typography, an oval seal, a standalone symbol, a flag, and selected lockups. All lettering is outlined and each SVG is self-contained.

Rebuild with `.design/fictional-roster/generate.py`. The first fictional-logo set is backed up in `.design/fictional-roster/variants-v2/before/`. The former JAPAC company roster is preserved in `.design/future-customer-roster/` and its original files remain in `public/brands/`.
